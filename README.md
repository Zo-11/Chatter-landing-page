# Chatter landing page

A responsive static HTML and CSS implementation of the Chatter landing page shown in the supplied Figma screenshot.

## Run locally

Open `index.html` in a browser. The four community portraits are local files in `assets/`; the page uses a Google Font and Unsplash URLs for the hero and library photography, so an internet connection is needed for those visual assets.

## Page structure

- `index.html` contains the semantic sections and copy.
- `styles.css` contains the color tokens, desktop layout, responsive breakpoints, and reduced-motion handling.

## Publish

This is a static site and can be served directly from GitHub Pages, Netlify, or Vercel. Set the publish directory to the repository root (or `outputs/` if the folder is kept as-is).
